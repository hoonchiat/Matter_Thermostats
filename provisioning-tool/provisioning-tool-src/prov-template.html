Matter Provisioning Station

Flashes a unique commissioning identity (discriminator + passcode + serial) into each ESP32-C6 Light or Button, keeps a device database, and prints a QR label. Firmware is embedded — works offline in desktop Chrome/Edge.
Only the Light and Button carry a per-device identity. To flash the Hub or Gateway Portal (or plain-flash a Light/Button without changing its identity), use flash-tool.html instead.
Web Serial not available. Open this in desktop Chrome or Edge.
1 · Device database
The database auto-increments serials, discriminators and passcodes and remembers what's been flashed. It's a file you own.
