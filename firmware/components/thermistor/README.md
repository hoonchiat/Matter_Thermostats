# thermistor

10K NTC (HVAC **Type 2 / Type 3**) temperature sensing.

- **Pure conversion** (`ntc_curves.c`, no ESP dependency): millivolts → resistance →
  temperature via per-type LUT with ln(R)-linear interpolation. Unit-tested on host.
- **ADC driver** (`thermistor.c`): ESP-IDF v5 ADC oneshot + curve-fitting calibration,
  median-of-N raw filtering, EMA smoothing, calibration offset, and open/short fault
  detection.

## Curve data

`ntc_type2_lut.inc` / `ntc_type3_lut.inc` are generated by
[`tools/gen_ntc_lut.py`](../../../tools/gen_ntc_lut.py). The checked-in tables use the
*nominal* β model (Type 2 ≈ 3891 K, Type 3 ≈ 3976 K). **For field accuracy, regenerate
from the sensor manufacturer's R-T table:**

```bash
python3 tools/gen_ntc_lut.py --csv type3_datasheet.csv --name ntc_type3_lut \
    > firmware/components/thermistor/ntc_type3_lut.inc
```

## Divider assumption

Fixed reference resistor on top (to Vref), NTC on the bottom (to GND); the ADC reads the
node. `R = Rfix · V/(Vref−V)`. See [../../../docs/HARDWARE.md](../../../docs/HARDWARE.md#thermistor-front-end).
